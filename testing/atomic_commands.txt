TESTING NOTES
================================================================================

1. ALWAYS run these tests in an isolated lab environment
2. Configure Sysmon on Windows VMs before testing (use provided sysmon-config.xml)
3. Ensure SIEM is ingesting logs before running tests
4. Wait 30-60 seconds after each test for log ingestion
5. Validate detection in SIEM alert queue
6. Document any false negatives (missed detections)
7. Tune rules if false positives occur

1. Document the legitimate activity that triggered the alert
2. Identify the source (process, user, host)
3. Review docs/FALSE_POSITIVE_TUNING.md for guidance

5. Re-test to confirm false positive is eliminated
6. Verify true positive detection still works
